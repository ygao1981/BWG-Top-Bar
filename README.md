# BWG Top Bar — 搬瓦工 Windows 单行悬浮栏

默认放在屏幕顶部。可拖动、置顶、记住位置，右键设置连接、手动刷新和开机启动。窗口不预留屏幕工作区，能覆盖在其他窗口上；若挡住软件按钮，直接拖走即可。

**本包是修订后的项目源码，不含 EXE。已做源码审查，尚未在 Windows 编译或连接真实搬瓦工账号。不要把这份包当成已通过真机测试的发行版。**

## 显示什么

默认用 KiwiVM API 查询当前账期剩余流量、总额度和下次重置时间。能获取的运行状态、可用内存和负载也会显示。不能获取时显示未知或配额，不猜测剩余量。

示意（非真实账号数据）：

`BWG | 剩余流量 680/1000 GiB | 可用内存 1.4/2 GiB | 磁盘配额 40 GiB | 12天后重置`

启用 SSH 后，可显示 CPU 采样使用率、可用内存、根分区可用容量。没有启用 SSH 时，磁盘仅显示套餐配额。系统负载与 CPU 百分比是不同指标，界面分别标注。

- 普通缩放下高度约 32 像素；宽度根据内容和屏幕调整。
- 窄屏优先保留流量及重置时间，完整数据可在鼠标提示中查看。
- 查询失败时，在悬浮栏文字及指示灯中提示。保留的流量会标注“未更新”；资源查询失败则清除旧资源值。
- 流量已用达到 80% 时橙色，90% 时红色。有连接错误时优先显示警告色。
- 拖动悬浮栏不抢走其他软件的键盘焦点；设置窗口正常接受输入。
- 支持一台 VPS。多个 VPS、历史曲线、通知推送和全屏自动隐藏不在本版范围内。

## Windows 编译与启动

1. 安装微软 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。需要 SDK，只有运行时不能编译。
2. 解压后，在项目根目录打开 PowerShell，执行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build-win.ps1
   ```

3. 成功后运行 `publish\win-x64\BwgTopBar.exe`。
4. 在程序设置窗口填写你自己的 VEID 和 KiwiVM API Key，保存并刷新。
5. 在 KiwiVM 面板核对一次流量和重置日期。数据确认一致后，再通过右键菜单开启开机启动。

构建脚本使用独立单文件发布，目标电脑不需要另装 .NET 运行时。第一次构建需要联网还原官方运行库。ARM64 Windows 可追加 `-Runtime win-arm64`，本次未验证 ARM64。

本次将构建目标从 .NET 8 更新到 .NET 10 LTS。根据[微软生命周期说明](https://learn.microsoft.com/en-us/lifecycle/products/microsoft-net-and-net-core)，.NET 8 的支持截至 2026-11-10，.NET 10 的支持截至 2028-11-14。

## 只看流量：不需要 SSH

默认每 2 分钟请求一次流量，设置中可调为 2—30 分钟。VPS 实时状态最多每 5 分钟尝试一次；实际触发时刻跟随流量刷新，所以默认约每 6 分钟一次。

这些间隔是本程序的设计选择，不代表搬瓦工承诺的数据实时性或固定 API 限额。悬浮栏显示的是最近一次读取结果，并非逐秒推送。手动刷新适合连接排查，不应持续连点。

API 请求直接从你的 Windows 电脑发送到 `https://api.64clouds.com/v1/`，只允许 `getServiceInfo` 和 `getLiveServiceInfo` 两个查询接口。没有第三方服务中转。

## 可选 SSH：读取真实资源

如果你需要实际 CPU、可用内存及根分区可用容量，在设置中启用 SSH。程序调用 Windows OpenSSH，使用现有公钥登录，不收集或保存 SSH 密码。

先在本机终端自行连通，并确认服务器指纹。下面仅为参数占位示例：

```powershell
ssh -p 你的端口 你的用户名@你的服务器地址
```

设置中的私钥路径可以留空，OpenSSH 会按本机配置选择密钥；也可以指定已有私钥文件。带口令的密钥应先加入你自己的 ssh-agent，程序使用 `BatchMode=yes` 无交互认证。

程序固定运行 `head /proc/stat`、`free -b`、`df -P -B1 /`，仅查询数据；CPU 取一秒采样平均。查询需要服务器已有这些标准 Linux 命令及 `free` 的 available 列，不会自动安装软件。

磁盘显示的是根分区 `/` 的可用容量，不包含单独挂载的数据盘汇总。缺少命令、登录失败或主机指纹不匹配时，会提示资源未更新；已经成功读取的流量仍可展示。

## 数据口径与验证边界

- 保留初版的系数处理：额度 = `plan_monthly_data × monthly_data_multiplier`，已用 = `data_counter × monthly_data_multiplier`。剩余取二者之差，低于 0 时显示 0。
- 倍率缺失按 1 兼容；倍率为 0、负数或格式异常时拒绝更新，避免静默计算错值。
- 本次未能取得可直接访问的官方字段文档，也没有真实账号。公式仍需首次接入后与 KiwiVM 面板核对，尤其是倍率不为 1 的套餐。
- 单位采用 GiB，即 1024³ 字节。若控制台使用不同单位，要先统一单位再比较。
- 账期由 `data_next_reset` 决定，不假设每月 1 日重置。字段缺失或无效时显示未知。
- 内存总量优先显示套餐配额；SSH 的 Linux MemTotal 可能略低于套餐值。
- 资源查询不会修改流量的最后成功时间；查询资源失败不会冒充流量失败。

## 本地配置

API Key 写入当前用户的 Windows 凭据管理器，目标名 `BwgTopBar/KiwiVmApiKey`。其他配置位于 `%APPDATA%\BwgTopBar\settings.json`，不包含 API Key。开机启动使用当前用户启动项，不要求管理员权限。

使用你信任的 API Key，仅在本机设置窗口输入。无需把密钥发到聊天、仓库或在线监控站点。

退出后可删除程序目录。若需要彻底移除，先在右键菜单关闭开机启动；再自行删除上述配置目录及对应 Windows 通用凭据。
